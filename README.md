# FalsePositives-CRCscreening
Participant characteristics associated with false positive faecal occult blood test results in screening for colorectal cancer – a systematic review and meta-analysis

For the statistical analysis and the production of all results except Figure 2, we used Stata 18.5 BE and applied the below do-files 1 to 16. For Figure 2, we used R Studio 2026.05.0+218 and the packages forestplot, tidyr, and dplyr, and applied Script 1.
